经过对希柏瑜伽网站的深入分析，这个项目基础扎实，技术栈现代（Next.js 16 + Tailwind CSS 4），但在视觉冲击力、交互体验和功能完整性上还有很大的提升空间。让我从视觉升级、交互增强和功能扩展三个维度，给你一个系统的优化方案。

一、视觉升级：从"清晰"到"惊艳"
1.1 Hero 区域：打造电影级开场
现状：静态背景图 + 简单文字遮罩，缺乏动感和沉浸感。
优化方案：

视频背景 + 视差滚动：将静态图片替换为高质量瑜伽练习视频（建议使用 WebP 格式，压缩至 2-3MB），配合鼠标移动视差效果，营造沉浸感。
动态粒子效果：添加轻量级 Canvas 粒子背景（使用 react-particles），粒子随鼠标流动，体现"呼吸感"和"能量流动"。
渐变遮罩升级：从单一的黑色 bg-black/50 改为径向渐变（bg-gradient-to-br from-black/70 via-black/40 to-transparent），让文字更突出。
文字动画：标题使用 framer-motion 实现逐字淡入 + 轻微上浮，副标题延迟 300ms 出现，按钮延迟 600ms 出现。

代码示例：tsx// Hero.tsx 优化
import { motion } from 'framer-motion';

<motion.h2 
  initial={{ opacity: 0, y: 30 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.8, ease: "easeOut" }}
  className="text-4xl md:text-6xl font-bold mb-6 leading-tight"
>
  发现内心的平静与力量
</motion.h2>

建立完整的品牌色板，在 tailwind.config.ts 中扩展：tscolors: {

二、交互增强：从"展示"到"体验"
2.1 滚动动画：让页面"活"起来
现状：所有内容静态展示，缺乏动态引导。
优化方案：
使用 framer-motion 的 useInView 实现滚动触发动画：tsximport { motion, useInView } from 'framer-motion';
import { useRef } from 'react';

const ScrollReveal = ({ children }: { children: React.ReactNode }) => {
  const ref = useRef(null);
  const isInView = useInView(ref, { once: true, margin: "-100px" });

  return (
    <motion.div
      ref={ref}
      initial={{ opacity: 0, y: 50 }}
      animate={isInView ? { opacity: 1, y: 0 } : {}}
      transition={{ duration: 0.6, ease: "easeOut" }}
    >
      {children}
    </motion.div>
  );
};

在各个组件标题、卡片上包裹此组件，形成"依次浮现"的节奏感。

2.2 鼠标跟随效果：增强沉浸感
现状：无鼠标交互反馈。
优化方案：
在 Hero 区域和 Gallery 添加鼠标跟随光晕：tsxconst MouseGlow = () => {
  const [mousePosition, setMousePosition] = useState({ x: 0, y: 0 });

  useEffect(() => {
    const handleMouseMove = (e: MouseEvent) => {
      setMousePosition({ x: e.clientX, y: e.clientY });
    };
    window.addEventListener('mousemove', handleMouseMove);
    return () => window.removeEventListener('mousemove', handleMouseMove);
  }, []);

  return (
    <div
      className="fixed w-96 h-96 rounded-full bg-brand-accent/20 blur-3xl pointer-events-none"
      style={{
        left: mousePosition.x - 192,
        top: mousePosition.y - 192,
      }}
    />
  );
};


2.3 图片懒加载与加载动画
现状：Unsplash 图片加载可能较慢，无加载状态。
优化方案：tsximport Image from 'next/image';
import { useState } from 'react';

const LazyImage = ({ src, alt }: { src: string; alt: string }) => {
  const [isLoading, setIsLoading] = useState(true);

  return (
    <div className="relative overflow-hidden rounded-lg">
      <Image
        src={src}
        alt={alt}
        width={600}
        height={400}
        className={`transition-opacity duration-500 ${isLoading ? 'opacity-0' : 'opacity-100'}`}
        onLoad={() => setIsLoading(false)}
      />
      {isLoading && (
        <div className="absolute inset-0 bg-gradient-to-br from-brand-light to-gray-200 animate-pulse" />
      )}
    </div>
  );
};

在线课程筛选与排序
为在线课程添加筛选功能：tsx// 新建 hooks/useCourseFilter.ts
export const useCourseFilter = (courses: OnlineCourse[]) => {
  const [filter, setFilter] = useState<'all' | 'popular' | 'price-low' | 'price-high'>('all');

  const filteredCourses = useMemo(() => {
    switch (filter) {
      case 'price-low':
        return [...courses].sort((a, b) => a.price - b.price);
      case 'price-high':
        return [...courses].sort((a, b) => b.price - a.price);
      default:
        return courses;
    }
  }, [filter, courses]);

  return { filteredCourses, filter, setFilter };
};
