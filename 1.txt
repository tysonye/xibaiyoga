🔍 根因分析

问题定位：部署配置错误

1. GitHub Pages 部署配置检查

根据 README.md 说明，项目使用 GitHub Actions 自动部署，配置文件应位于：

plaintext
.github/workflows/deploy.yml


可能的问题：

❌ GitHub Actions 工作流未正确配置
❌ next.config.ts 中 output: 'export' 未生效
❌ out/ 目录未正确上传或同步
❌ 构建失败但未报错（静默失败）

2. Next.js 静态导出配置

当前配置（推测）：

typescript
// next.config.ts
export default {
  output: 'export',
  // ... 其他配置
}


问题分析：

Next.js 16 的静态导出会将构建产物输出到 out/ 目录
如果 GitHub Pages 配置的发布分支不是包含 out/ 的分支，会导致旧版本在线
需要确认 GitHub Pages 设置中的 Source 和 Branch

3. 构建产物验证

当前线上版本的 HTML 特征：

❌ 无 framer-motion 相关的 CSS 类名
❌ 无 swiper 相关的 DOM 结构
❌ 无 lazy-image 的 data 属性
❌ 所有 JavaScript 都在客户端直接渲染（无 SSR）

结论： 线上版本是纯静态 HTML，可能是 Next.js 早期版本的构建产物，或者根本未使用 Next.js 构建。

name: Deploy to GitHub Pages

on:
  push:
    branches: [ master, main ]

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run build
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./out  # 关键：Next.js 静态导出目录
